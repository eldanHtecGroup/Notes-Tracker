  To show the pattern working end to end, I added a small example feature for
  notes:
  - Endpoints: GET /api/health and GET/POST/PUT/DELETE /api/notes.
  - Responses: successful calls return { data }, and errors return { error: {
    message, details? } }.
  - Storage: notes are kept in memory, so they're lost when the server restarts.
    When you add a real database, only the repository files need to change.

  To run it: in backend/, run npm run dev for auto-reload while you work, or npm
  start.

    dotenv.

    my cleanup command force-closed every running node.exe. If any of your other
    Node tools stopped, that was me. Restart them and they'll be fine.
