  optional.
  ────────────────────────────────────────
  Requirement: View a list of all saved notes
  Status: ✅
  Where: GET /api/notes lists the most recently modified first. The UI shows
  them
  in NoteList.jsx (frontend/src/components/NoteList.jsx) and NoteItem.jsx
  (frontend/src/components/NoteItem.jsx).
  ────────────────────────────────────────
  Requirement: Edit existing notes
  Status: ✅
  Where: PATCH /api/notes/:id changes only the fields you send. The UI edits in
  place in NoteItem.
  ────────────────────────────────────────
  Requirement: Delete unwanted notes
  Status: ✅
  Where: DELETE /api/notes/:id. The UI asks you to confirm first.
  ────────────────────────────────────────
  Requirement: Each note shows when it was last modified
  Status: ✅
  Where: updatedAt is set when a note is created and refreshed on every update.

  ────────────────────────────────────────
